## FAQ

### Is OmniPatch safe to use?

Yes, OmniPatch is designed with safety in mind. It does not contain tool, does not connect to external servers, and operates locally on your machine. We recommend running it in a virtual environment for added security.

### Which applications are currently supported?

OmniPatch supports the latest stable versions of ChatGPT Desktop, Claude, Perplexity AI, Microsoft Copilot, Cursor IDE, GitHub Copilot, Devin, and JetBrains IDEs with their AI Assistant plugin.

### How often is OmniPatch updated?

We aim to release updates within 48-72 hours after a major update to any of the supported applications, ensuring continued compatibility and effectiveness.

### Will this affect my original application data or projects?

No, OmniPatch modifies only the application executable and licensing files. Your user data, projects, and settings remain completely untouched and safe.

### Do I need an internet connection to use OmniPatch?

An internet connection is required only for the initial download of the patcher and for the applications themselves to function. OmniPatch activation works offline after the patch is applied.

### Is there a free trial or is this a one-time payment?

OmniPatch is provided as a free utility for the community. There are no payments, subscriptions, or in-app purchases required to use its full functionality.

### What are the system requirements?

OmniPatch requires Windows 10 or 11, a minimum of 4 GB RAM, and administrative privileges to modify application files. Supported applications must be installed prior to patching.

### Can I revert the changes if something goes wrong?

Yes, OmniPatch automatically creates backups of the original files before patching. You can use the 'Restore Originals' function within the tool to revert all changes.

### Does this work with portable or non-standard installations?

OmniPatch detects standard installation paths. For non-standard installations, you can manually specify the application's executable file path within the tool's advanced settings.
